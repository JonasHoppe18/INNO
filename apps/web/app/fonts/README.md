# Inter

Inter 4.1 variable fonts, unmodified, from the official [rsms/inter release](https://github.com/rsms/inter/tree/v4.1/docs/font-files).

- InterVariable.woff2 — normal, weights 100–900
- InterVariable-Italic.woff2 — italic, weights 100–900
- LICENSE.txt — SIL Open Font License 1.1

Loaded with next/font/local in app/layout.jsx. Shopify publishes Inter as the sans family in its [Polaris font tokens](https://github.com/Shopify/polaris-react-archive/blob/main/polaris-tokens/src/themes/base/font.ts). These are upstream Inter files, not copied Shopify UI assets.
